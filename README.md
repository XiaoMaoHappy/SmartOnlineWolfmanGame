# 🐺 人不够 AI 来凑的狼人杀<br><br>—— 基于 华为云MaaS模型即服务 的 线上狼人杀智能对局平台

最新版本号：v1.0.5

发布日期：2026年10月28日

> 基于 Flask + 大模型 AI 的在线狼人杀对局平台，支持 6–12 人配置，真人玩家与 AI 玩家混合对战，浏览器直接游玩。

---

## 🚀 快速开始

### 1. 双击 `start.bat` 以启动服务端；

### 2. 浏览器打开 [http://localhost:60081/](http://localhost:60081/)；

### 3. 如需和其他设备联机，请手动开放防火墙中的 60081 端口；

### 4. 点击「创建房间」，设置玩家数量（6–12 人）和 AI 数量；

### 5. 点击「加入房间」，等待房主开始游戏；

### 6. 游戏开始后，按编号顺序依次发言、投票、执行夜间行动；

### 7. 游戏结束后，可在「复盘」页面查看详细记录，可按「再来一局」重新开始。

## ✨ 功能概览

### 核心玩法
- **6–12 人灵活配置**：按人数自动分配角色（狼人 /3 狼美人、预言家、女巫、猎人、守卫、平民），房主也可自定义角色配置
- **完整昼夜循环**：夜晚（狼刀→狼美人魅惑→预言家查验→女巫用药→守卫守护）→ 白天（公布死讯→依次发言→投票放逐→遗言→技能结算）→ 胜负判定
- **三种胜利条件**：默认（屠边+屠城）、屠边（神职或平民全灭）、屠城（狼数≥好人）

### AI 大模型接入
- **DeepSeek 大模型驱动**：AI 玩家通过华为云 ModelArts MaaS 接入 DeepSeek 模型，自主完成夜间行动、白天发言、投票、遗言等全部决策
- **线程化 AI 调用**：每次询问 AI 开启独立线程，带超时控制（夜间≤10s / 发言≤30s），超时自动走启发式兜底，保证对局不卡死
- **精简提示词**：随回合增长自动控制 prompt 长度，聊天记录/出局历史限量截取，确保大模型快速响应
- **AI 狼人协作出刀**：狼人环节征询所有狼人刀口意见，优先真人狼人，真人平票随机选取，确定刀口后再显示给女巫
- **AI 发言/遗言**：白天发言和被放逐遗言均由大模型生成符合身份的文本，失败时模板兜底

### 真人玩家体验
- **玩家编号 1–12**：每局随机编号，发言/UI/AI 提示词均按编号顺序
- **浏览器直连**：无需安装客户端，打开网页即玩
- **SSE 实时推送**：状态变更主动推送，500ms轮询兜底
- **发言超时强制发送**：超时时自动发送输入框内容，无内容则放弃发言
- **遗言阶段**：被放逐者有 60 秒遗言时间（含 AI），遗言在玩家名称旁标注「（遗言）」
- **投票倒计时**：投票阶段显示剩余时间，超时自动弃票
- **猎人开枪确认**：选中目标后弹出确认框，防止误操作

### 房间管理
- **房主设置页**：配置 AI 数量、角色配置、胜利条件
- **角色配置展示**：准备页面向所有玩家显示当前角色配置
- **玩家退出/房主移交**：房主退出自动移交给剩余真人玩家，无真人则关闭房间
- **闪退接管**：真人玩家超时未活动由 AI 临时接管，返回后恢复控制
- **再来一局**：游戏结束后房主可重开，保留房间和玩家名单

### 结算复盘
- **复盘页面**：游戏结束显示所有玩家角色、夜间操作记录、投票记录
- **开放聊天**：游戏结束后开放真人玩家间自由聊天
- **系统消息**：第 n 回合开始时自动发送系统消息

## 🏗️ 技术架构

```
./
├── game.py          # 核心游戏引擎（纯逻辑，可独立单测）
├── bot.py           # AI 玩家接入层（提示词构造 + 大模型调用 + 后台驱动）
├── ai.py            # 大模型 API 封装（华为云 ModelArts MaaS / DeepSeek）
├── app.py           # Flask REST API + SSE 推送
├── storage.py       # 房间数据持久化（JSON 序列化）
├── static/
│   └── index.html   # 前端单页应用（原生 JS，无框架）
├── tests/           # 单元测试（37 个测试用例）
├── run.py           # 开发启动入口
├── gunicorn_config.py  # 生产部署配置
└── requirements.txt
```

### 技术栈
| 层 | 技术 |
|---|---|
| 后端 | Flask + threading + SSE |
| AI | 华为云 ModelArts MaaS → `DeepSeek-V4-Flash` 大模型 |
| 前端 | 原生 HTML/CSS/JS（无框架，单文件） |
| 持久化 | JSON 文件存储 |
| 部署 | Gunicorn + Gevent / IPv6 双栈 |

## 🎮 游戏规则

### 角色说明
| 角色 | 阵营 | 技能 |
|------|------|------|
| 狼人 | 狼人 | 夜晚与狼队友共同选定一名玩家击杀 |
| 狼美人 | 狼人 | 被投票放逐时可魅惑一名存活玩家同归于尽 |
| 预言家 | 好人 | 每晚查验一名玩家阵营 |
| 女巫 | 好人 | 拥有解药（救当晚被刀者）和毒药（毒杀一名玩家），各限用一次 |
| 猎人 | 好人 | 被狼刀或被放逐时可开枪带走一名玩家（被毒/被魅惑不可） |
| 守卫 | 好人 | 每晚守护一名玩家，被守护者当晚免疫狼刀 |
| 平民 | 好人 | 无夜间技能，靠发言和投票找出狼人 |

### 昼夜流程
1. **夜晚**：守卫选守 → 狼人选刀 → 狼美人魅惑 → 预言家查验 → 女巫用药
2. **白天**：公布死讯 → 按编号顺序依次发言 → 投票放逐 → 被放逐者遗言 → 技能结算
3. **胜负判定**：狼人全灭→好人胜；狼数≥好人数 或 神职全灭/平民全灭→狼人胜

### 默认角色配置
| 人数 | 配置 |
|------|------|
| 6 人 | 狼2 平民3 预言家1 |
| 7 人 | 狼2 平民3 预言家1 女巫1 |
| 8 人 | 狼3 平民3 预言家1 女巫1 |
| 9 人| 狼2 狼美人1 平民3 预言家1 女巫1 猎人1 |
| 10 人 | 狼2 狼美人1 平民4 预言家1 女巫1 猎人1 |
| 11 人 | 狼2 狼美人1 平民4 预言家1 女巫1 猎人2 |
| 12 人 | 狼2 狼美人1 平民5 预言家1 女巫1 猎人2 |

## 📡 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/rooms` | 创建房间 |
| POST | `/api/rooms/<id>/join` | 加入房间 |
| POST | `/api/rooms/<id>/start` | 开始游戏 |
| POST | `/api/rooms/<id>/config` | 修改设置（仅房主） |
| POST | `/api/rooms/<id>/action` | 提交行动 |
| POST | `/api/rooms/<id>/chat` | 发送发言 |
| GET | `/api/rooms/<id>/state` | 获取状态 |
| GET | `/api/rooms/<id>/stream` | SSE 推送 |
| POST | `/api/rooms/<id>/restart` | 再来一局 |
| POST | `/api/5rooms/<id>/leave` | 退出房间 |
